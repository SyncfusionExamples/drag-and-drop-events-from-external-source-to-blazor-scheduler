# Drag and Drop Events from External Source to Blazor Scheduler

A quick start Blazor project that helps you to learn how to drag an item from an external TreeView component and drop it as an appointment onto the [Blazor Scheduler](https://www.syncfusion.com/scheduler-sdk/blazor-scheduler).

## Features

* Seamless drag-and-drop integration from external TreeView components
* Real-time appointment creation through drag-and-drop interactions
* Synchronized data between external sources and the Scheduler
* Interactive UI with TreeView and Scheduler components

## Prerequisites

- Visual Studio 2026 or Visual Studio Code
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

## How to run the project

**Visual Studio 2026**:

* Checkout this project to a location in your disk.
* Open the project (`DragDropEvents.csproj`) file.
* Restore the NuGet packages.
* Run the project.

**Visual Studio Code**:

* Open the repository folder in Visual Studio Code.
* Open the integrated terminal.
* Navigate to the repository root.

```bash
cd drag-and-drop-events-from-external-source-to-blazor-scheduler
dotnet restore
dotnet run
```

Open the URL displayed in the terminal after the application starts.
